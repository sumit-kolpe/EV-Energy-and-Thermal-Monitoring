## What the real data looks like (Phase 1 findings)
- 98,061,214 raw readings, 7 vehicles (CUP1–5 = CUPRA Born, ID1–2 = VW ID.3). 29 signals defined, **15 contain data**.
- **No HV battery current, no motor RPM, no odometer.** Energy = SOC %/100 km; distance = ∫speed dt; use speed/acceleration instead of RPM.
- CUPRAs logged Nov 2022 – May 2023 only (winter/spring); ID.3s Feb 2021 – Oct 2023.
- 812 CUP1 readings had impossible timestamps (year 2087) → dropped.
- Battery pack max temp (`bat_temp`, id 1209) is logged in bursts; interpolated across gaps ≤ 10 min (flag `bat_temp_observed`). Coolant outlet temp (`bat_outlet_temp`) is a dense backup thermal target.
- Coolant inlet/outlet temps contain placeholder 0.00 and 1023.98 values → set to NaN.
- Result: 911k rows on the 10 s grid (290k driving rows), 2,389 trips, 43.7k km. See `reports/eda_summary.md`.

### Rules that keep Phase 3 honest
- Split train/test **by trip or by vehicle** (GroupKFold), never by random rows.
- For "rest of trip" / "5 min ahead" models, use only rows up to the prediction time (`trip_elapsed_s`), not whole-trip features (including the driving regime).
- Energy target: `soc_per_100km` (or `kwh_per_100km` if `hv_current` exists), using the `energy_valid_5km` / `energy_valid_20km` filters.
